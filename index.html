После покупки вы получите сообщение в боте с данными аккаунта: Email, Пароль и код 2FA. На каждом шаге ниже мы покажем анимацию — как правильно скопировать данные, не захватив лишние пробелы.

● Шаг 1
Настройка прокси для ПК

Настройте доступ через США для стабильной работы сервисов Google (если используете наши прокси). Выберите подходящий способ для ПК.

Уже есть свой надёжный VPN на США?

Если у вас уже есть проверенный и стабильный VPN с локацией США (USA), настраивать прокси не обязательно — можете смело пропустить этот этап и сразу переходить ко Шагу 2: Вход в аккаунт. Но если с VPN возникают сложности, сервисы не открываются или режет по региону — индивидуальные приватные прокси США всегда можно приобрести прямо у нас внутри бота.

Лёгкий и удобный способ (Рекомендуется)

Прокси будет работать только внутри вашего браузера. Остальные программы и игры на компьютере будут работать напрямую, с Вашего реального IP.

  1. Скачайте расширение для браузера Zero Omega из официального магазина Chrome.
  2. В правом верхнем углу браузера (в списке расширений) появится черный кружок. Нажмите на него и выберите Options.
  3. В открывшемся окне перейдите во вкладку New profile... слева.
  4. В поле Profile name введите любое удобное название (например, Veo). Убедитесь, что выбран тип Proxy profile и нажмите Create.
  5. В появившемся окне настроек:
    • Protocol — выберите HTTP
    • Server — вставьте ваш IP-адрес из бота
    • Port — вставьте ваш порт
    Нажмите на значок замочка (Lock) справа.
  6. Появятся поля для авторизации. Введите Username (логин) и Password (пароль), которые пришли в боте. Затем слева внизу нажмите зелёную кнопку Save changes (сохранить).
  7. Почти всё! Теперь снова нажмите на черный кружок Zero Omega в браузере и выберите название, которое Вы задали для Вашего профиля.

✅ Готово! Теперь ваш браузер работает через прокси. Можно переходить к следующему шагу.

Прокси только для среды разработки

Подойдет, если вы хотите пустить через прокси только саму программу Antigravity, а весь остальной трафик на ПК оставить без изменений.

  1. Скачайте и установите программу ProxyBridge (выбирайте самый верхний файл .exe в разделе Assets). Устанавливайте стандартно, со всем соглашаясь.
  2. ОБЯЗАТЕЛЬНО запустите установленный ProxyBridge от имени Администратора (правая кнопка мыши → Запуск от имени администратора).
  3. В главном окне ProxyBridge нажмите меню Proxy → Proxy Settings.
  4. Заполните поля данными из бота:
    • Proxy Type — HTTP
    • Proxy Host — ваш IP-адрес
    • Proxy Port — ваш порт
    • Proxy Username и Proxy Password — ваш логин и пароль.
    Нажмите Save Changes.
  5. Теперь нужно задать правила. Нажмите меню Proxy → Proxy Rules. Нажмите синюю кнопку Add.

    Вам нужно добавить 4 правила. Нажмите Browse и найдите эти процессы в папке установки (обычно %localappdata%\Programs\Antigravity):
    1. Antigravity.exe
    2. language_server.exe
    3. webm_encoder.exe
    4. elevate.exe

    Для каждого выберите файл и нажмите Save Rule. Итог должен выглядеть так:

Как полноценный VPN

Этот способ пропускает ВЕСЬ трафик вашего компьютера через прокси. Отлично подойдет, если вам нужен глобальный обход ограничений.

  1. Скачайте и установите программу ProxyBridge (выбирайте самый верхний файл .exe в разделе Assets). Устанавливайте стандартно, со всем соглашаясь.
  2. ОБЯЗАТЕЛЬНО запустите установленный ProxyBridge от имени Администратора (правая кнопка мыши → Запуск от имени администратора).
  3. В главном окне ProxyBridge нажмите меню Proxy → Proxy Settings.
  4. Заполните поля данными из бота:
    • Proxy Type — HTTP
    • Proxy Host — ваш IP-адрес
    • Proxy Port — ваш порт
    • Proxy Username и Proxy Password — ваш логин и пароль.
    Нажмите Save Changes.
  5. Теперь направим весь трафик. Нажмите меню Proxy → Proxy Rules. Нажмите синюю кнопку Add.

    В поле Applications введите звёздочку * (это означает «для всех программ»). Остальные настройки менять не нужно. Нажмите Save Rule.

✅ Готово! Чтобы «выключить VPN» — просто закройте ProxyBridge.

Для телефона (iOS)

Нам понадобится приложение Happ Plus. Если у вас русский AppStore, его может там не быть. Посмотрите эту короткую инструкцию (1 минута) о том, как быстро сменить регион, после чего приложение появится в поиске.

  1. Скачайте и откройте приложение Happ Plus.
  2. Сверху в правом углу нажмите значок «+».
  3. В появившемся меню выберите пункт «Ручной ввод».
  4. В открывшемся окне по умолчанию стоит протокол VMess. Нажмите на него и выберите протокол «Socks».
  5. Далее откроется стандартный вариант ввода. В поле «Имя» напишите любое название, например «VPN». Остальные данные заполняйте строго в таком порядке: IP, Порт, Логин, Пароль.

✅ Сохраните и подключитесь!

Для телефона (Android)
  1. Скачайте приложение Super Proxy из Google Play.
  2. Откройте приложение и создайте новый профиль (нажмите Add proxy).
  3. Заполните все данные для подключения: IP / Server, Port, Protocol (выберите HTTP), Authentication (ваш логин и пароль).
  4. Сохраните настройки, выберите созданный профиль и нажмите Подключить (Start).

✅ Готово! Ваш телефон теперь защищен прокси.

Частые вопросы по прокси

Чаще всего проблема кроется в лишних пробелах, которые случайно захватываются при копировании данных из бота.

Убедитесь, что вы выделяете текст чётко от первого до последнего символа, как показано на анимации ниже:

Благодарим за покупку! ♥️

Ваш IP: 185.12.34.56

Порт: 1080
Логин: user123
Пароль: pass456
14:02

Прокси уже настроены на США (USA). Это идеально подходит для работы со всеми сервисами Google.

Проверить свою текущую геопозицию после включения прокси можно на сайте: whoer.net/ru.

Да, вы можете подключить свои основные устройства, например: ПК, телефон или планшет.

Крайне не рекомендуем передавать прокси-данные кому-то ещё или использовать их на десятках разных устройств одновременно. С огромной вероятностью такие прокси попадут в черный список системы безопасности Google.

Спустя 30 дней просто приобретите прокси в боте повторно. Новые данные придут вам таким же сообщением, и вам нужно будет просто обновить их в вашем приложении (Zero Omega, Happ Plus и т.д.).

Получение кода 2FA

Теперь вам нужно получить 6-значный код для входа с помощью ключа 2FA из сообщения бота.

  1. Скопируйте специальный код (2FA) из сообщения бота.
  2. Перейдите на сайт для получения 2FA.
  3. Вставьте скопированный код в верхнее поле.
  4. Скопируйте полученный 6-значный код из нижнего поля.
  5. Вставьте этот 6-значный код на странице входа в Google.
  6. После прохождения 2FA Google может предложить привязать ваш резервный номер телефона или адрес почты. Это делать не обязательно (и всегда можно сделать в настройках аккаунта позже), поэтому сейчас нажимаем "Cancel".
Если после 2FA появилось окно «Проверьте свои данные» (QR-код или SMS)

Это новый формат проверки от Google, который иногда появляется после ввода кода 2FA. Ниже — готовая инструкция и скрипт, как его быстро пройти:

📥 Скачать «Скрипт QR»
  1. При авторизации на странице «Проверьте свои данные» выберите подтверждение через QR-код (первый пункт, «Отсканировать QR-код»).
  2. Скачайте файл «Скрипт QR» по кнопке выше и скопируйте весь его текст целиком (или просто нажмите кнопку «Скопировать скрипт»).
  3. На открытой странице с QR-кодом нажмите клавишу F12 и перейдите во вкладку Console (Консоль). Сначала попробуйте вставить скопированный текст в консоль — браузер выдаст ошибку защиты, так и нужно. Сразу после этого пропишите вручную allow pasting и нажмите Enter.
  4. Ещё раз вставьте содержимое файла в консоль и нажмите Enter на клавиатуре.
  5. Следите за статусом: иногда может выдать ошибку, в этом случае просто перезайдите / обновите страницу с QR-кодом и повторите процедуру. В редких случаях ошибка может выбивать и по 4 раза, но в большинстве случаев проходит с 1-й же попытки, реже — с нескольких.
Главный маркер, что процесс запустился

На странице с QR-кодом появится кружок загрузки и надписи вроде Wait, Process и т.д. — просто дождитесь завершения проверки.

Частые вопросы

Убедитесь что скопировали данные из бота корректно, не захватили лишних пробелов и выделили абсолютно все символы.

Не переживайте, здесь либо сбился регион на аккаунте, либо проблема в VPN — это легко исправить:

  1. Вероятнее всего, у вас сбился регион на аккаунте. Перейдите по ссылке policies.google.com/country-association-form и заполните апелляцию на смену региона точно так же, как у нас на скриншоте. Обязательно проверьте, чтобы справа сверху (там будет аватарка — на неё можно нажать и посмотреть адрес почты) был выбран нужный купленный аккаунт.
    Скриншот: смена региона
  2. Если смена региона не поможет решить проблему, значит, скорее всего дело в VPN. Чинится это тоже весьма просто — нужно сменить VPN-сервис/сервер на другую локацию США, либо, если нет рабочих вариантов под рукой, перейти на наши приватные прокси из бота, они уже настроены на США и заточены под стабильную работу со всеми сервисами.

Чтобы сменить язык интерфейса на русский, выполните следующие шаги:

  1. Нажмите на аватарку аккаунта в правом верхнем углу.
  2. Выберите пункт "Manage your Google Account" (Управление аккаунтом).
  3. В меню слева перейдите в раздел "Personal info" (Личная информация).
  4. Пролистайте страницу чуть ниже и найдите пункт "Language" (Язык).
  5. Нажмите на иконку карандаша, введите "Russian" или "Русский", выберите его и сохраните изменения.
● Antigravity
Antigravity: Установка и вход

Среда разработки и агент-помощник от Google.

  1. Перейдите на официальный сайт Antigravity и скачайте установщик. После установки у вас появится две программы: Antigravity и Antigravity IDE. Вы можете использовать любую из них — интерфейс немного отличается, но функционал идентичен. Выбирайте то, что удобнее именно вам.
  2. Обязательно включите прокси на ПК!

    Для работы Antigravity необходимо, чтобы прокси-соединение было включено на всём ПК (через ProxyBridge или VPN), иначе при подключении к моделям Gemini будут возникать ошибки.

  3. Откройте приложение. Система сама предложит вам войти через почту и перебросит в браузер для стандартной авторизации Google.

Верификация (при первом входе)

При первой попытке входа Google может запросить прохождение верификации для подтверждения, что это именно вы.

  1. После ввода данных в самом приложении Antigravity появится окно с просьбой подтвердить личность. Нажмите кнопку Verify.
  2. Google предложит выбрать метод верификации. Выберите по QR-коду (иногда QR-код появляется сразу).
  3. Откройте камеру на вашем смартфоне и отсканируйте этот QR-код. Вас автоматически перебросит в приложение YouTube (неважно, какой именно аккаунт там сейчас авторизован).
  4. В YouTube появится окно с запросом на подтверждение входа. Просто нажмите кнопку подтверждения.
  5. На экране компьютера страница автоматически обновится и покажет успешное прохождение верификации.
  6. Вернитесь в приложение Antigravity и нажмите кнопку "Sign in again". Снова пройдите процесс входа — теперь верификация больше не потребуется, и вы успешно попадете в рабочую среду.

Сброс региона (Ineligible account)

Если при попытке войти в Antigravity вы видите ошибку "Sorry, this account is ineligible to use Antigravity", это значит, что у аккаунта "слетел" регион (например, если вы случайно пытались войти без включенного VPN/прокси). Это легко исправить.

  1. В окне с ошибкой Antigravity нажмите на ссылку FAQ.
  2. В открывшемся окне браузера найдите и нажмите на надпись "Submit a request".
  3. Вы попадете на форму запроса. Внимательно проверьте: в правом верхнем углу должна быть аватарка именно купленного Google-аккаунта (нажмите на неё, чтобы убедиться, что вы отправляете запрос с нужной почты).
  4. Заполните форму в точности так, как показано на скриншоте ниже, и нажмите Submit.
  5. Готово! Запрос на смену региона отправлен. Обычно в течение суток (чаще всего в тот же день) на эту почту придет письмо о том, что регион успешно изменен, и вы сможете войти в Antigravity.

Ошибка при выполнении запроса

Если во время работы в Antigravity при попытке обратиться к модели Gemini вы получаете ошибку "Agent execution terminated due to error", проблема кроется в вашем интернет-соединении.

  1. Убедитесь, что ваш прокси/VPN включен на всём ПК и работает корректно.
  2. Такая ошибка возникает, если система защиты Google видит ваш реальный IP-адрес, либо ваш VPN использует массовые публичные IP, которые Google блокирует.
  3. Чтобы убедиться, что проблема именно в IP, просто откройте сайт Gemini в браузере. С большой вероятностью вы увидите сообщение, что сервис недоступен в вашем регионе. Решение — использовать индивидуальные приватные прокси.

Как войти в почту Outlook (для кода подтверждения)

Иногда при входе с нового устройства CapCut присылает одноразовый 6-значный код на почту. У вас есть доступ к этому почтовому ящику:

  1. Перейдите на сайт почты outlook.live.com и нажмите Войти (Sign in).
  2. Введите Email из сообщения бота (первое поле) и нажмите Далее.
  3. Введите Пароль от почты (Outlook) — это третье поле из данных в боте (он отличается от пароля самого CapCut).
  4. Если Microsoft предложит добавить резервный способ входа — нажмите Пропустить / Skip for now (или Нет / No на окне «Не выходить из системы»).
  5. Откройте папку Входящие (Inbox) или Нежелательная почта (Junk), скопируйте код от CapCut и вставьте на странице входа.
